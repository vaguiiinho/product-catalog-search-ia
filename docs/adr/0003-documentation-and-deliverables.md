# ADR 0003 - Documentacao tecnica como entrega de primeira classe

## Status

Aprovado

## Contexto

O projeto e de portfolio e precisa comunicar bem suas decisoes, arquitetura e caminho de implementacao.

## Decisao

Manter documentacao formal com:

- `PRD`;
- `ADRs`;
- decisao arquitetural consolidada;
- checklist de implementacao.

## Alternativas consideradas

- documentacao solta em notas ou README unico;
- depender apenas de comentarios no codigo;
- documentar somente depois de implementar.

## Justificativa

- melhora a leitura do projeto por terceiros;
- facilita manter coerencia entre escopo e implementacao;
- registra decisoes dificeis de reverter;
- ajuda a apresentar o projeto em entrevistas e revisoes.

## Consequencias

- mais disciplina no inicio;
- menos risco de perda de contexto;
- trabalho extra pequeno, mas com alto retorno para o portfolio.
